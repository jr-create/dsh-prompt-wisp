feat: full settings page - every feature has an independent switch

The settings page now centralizes all six plugin options in two groups,
each switch labeled with its default value, one Save for all:

优化 (prompt optimization):
- 去废话 (trim filler)          default: off
- 详细优化 (detailed mode)      default: off

会话执行监控 (session execution watch):
- 显示会话监控告警条            default: on
  (showWatchBanner - off hides the banner AND stops polling)
- 卡死/死锁检测                 default: on
  (watchStall - 45s no-event rule)
- 无效输出检测                  default: on
  (watchNoOutput - 8+ steps with no visible text)
- 工具循环检测                  default: on
  (watchToolLoop - 5 near-identical tool calls)

Wiring: analyzeWatch takes watchStall/watchNoOutput/watchToolLoop
switches that gate their rules; readSessionWatch reads the persisted
config per poll (through a new watchConfigStore() accessor on http.js —
the host half cannot see http.js's module binding directly, and the
first live-host smoke run caught exactly that mistake as a
"configStore is not defined" crash before commit). The banner
component re-checks showWatchBanner on every poll, so toggling it
applies within one 5s interval without a page reload.

81 offline tests (was 80).
